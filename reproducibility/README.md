# Reproducibility Assets

This directory contains audit code, aggregate numerical outputs, and standalone
figures. It does not contain the manuscript, its bibliography, or conference
templates. Patient-level ADNI data are not redistributed.

## Numerical Audits

Run from `julia_alzheimer_pomdp/` with its pinned Julia environment:

```sh
julia --project=. ../reproducibility/audits/audit_metrics.jl
julia --project=. stats_paired.jl
```

`audits/camera_ready_metrics.json` records the input hash and summaries recomputed
from the archived ten-seed results. Overall accuracy weights episodes; macro
accuracy equally weights the three intake stages within each seed. The audit
does not rerun simulations or alter policy files.

With an authorized local dataset, run from `reproducibility/audits/` in PowerShell:

```powershell
./audit_visit_horizon.ps1 -Dataset 'PATH/TO/ADNI_POMDP_Complete.csv'
```

The read-only audit prints aggregate counts and a dataset hash. Its archived
output is `audits/camera_ready_visit_audit.json`. Maximum visits per participant
are 20 before diagnosis/MMSE exclusion and 19 afterwards. This supports the
original choice of H=20, but not an optimal horizon or a ten-year interpretation.
The notebook pools consecutive records without elapsed-time normalization.

## Figures

| Asset in `figures/` | Purpose and provenance |
|---|---|
| `fig1_actions_revised.tex`, `.pdf` | Illustrative action sequences for three simulated intake stages, redrawn from the existing examples; not a newly sampled experiment. |
| `fig_reward_distribution_by_state.png` | Discounted reward distributions by simulated intake stage and policy. |
| `v2_belief_trajectory.pdf` | Average target-state belief over decision visits. |
| `fig10_regions.pdf` | SARSOP belief-space decision regions. |

To regenerate the illustrative action figure, run from `reproducibility/figures/`:

```sh
pdflatex -interaction=nonstopmode -halt-on-error fig1_actions_revised.tex
```

This standalone figure source requires LaTeX with TikZ and the standalone class;
it is not manuscript source. The region figure is retained as an original vector
PDF. Its embedded title and excess vertical whitespace can be omitted on inclusion
with `trim=0 110 0 140,clip` (PDF points in left/bottom/right/top order), without
removing axes or the legend.

Julia figure-generation scripts and additional outputs remain in
`julia_alzheimer_pomdp/` and `julia_alzheimer_pomdp/figures_paper/`. They include
`generate_paper_figures_v2.jl`, `generate_reward_distribution.jl`,
`generate_belief_trajectory.jl`, and `extract_sarsop_policy.jl`. The assets above
preserve the selected presentation versions; the illustrative figure is manually
transcribed, not claimed to be regenerated by a fresh stochastic run.

## Sensitivity Evidence

`julia_alzheimer_pomdp/sensitivity_analysis.jl` and its archived JSON support the
reward perturbations: 1,000 episodes, seed 42, and a five-decision cap.
`sensitivity_cdr_raw.jl` and `sensitivity_cdr_output.txt` support the CDR MCI-row
perturbation: 10,000 episodes, seed 42, and a 20-decision cap. These protocols
differ from the main ten-seed benchmark; they do not establish independent
clinical validity or universally stable policy rankings.
